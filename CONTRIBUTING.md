# Contributing

## Branch naming

Use these prefixes so branches are easy to scan and sort:

| Prefix     | Use for |
|-----------|--------|
| `feature/` | New functionality or user-facing changes |
| `bugfix/`  | Fixing bugs (non-urgent) |
| `hotfix/`  | Urgent production fixes, often merged without full review cycle |
| `chore/`   | Tooling, config, deps, refactors, no user-facing change |
| `cleanup/` | Code cleanup, dead code removal, formatting, minor tidy-ups |
| `docs/`    | Documentation only |
| `test/`    | Adding or changing tests only |

**Format:** `prefix/short-description` (e.g. `feature/add-search`, `bugfix/login-redirect`, `chore/update-deps`).

Keep branch names short and lowercase; use hyphens for multiple words.
